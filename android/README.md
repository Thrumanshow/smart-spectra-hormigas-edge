# Android application

This repository contains the Android challenge prototype in `app/`. It integrates Presage SmartSpectra 3.4.0, requests camera consent and Android camera permission, evaluates session stability via `SmartSpectraConsensusEvaluator`, and builds an experimental 16-byte fixed LBH frame in memory via `PresageLbhBridge` and `LbhEncoder`.

The app evaluates valid pulse and breathing pairs over a 20-second experimental window and constructs the validated LBH frame in volatile memory when stability criteria are met. The generated byte array is held strictly in memory and is not transmitted over a network or persisted to disk.

Build and local development-key instructions are documented in the root README. A key injected into `BuildConfig` can be extracted from a built APK. Do not commit a credential or distribute an APK/AAB containing an active development key. The Presage SDK remains subject to Presage's own terms; this repository does not include its binary or provider demo assets.
