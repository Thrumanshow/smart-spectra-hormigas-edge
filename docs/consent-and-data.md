# Consent and data handling

This notice describes the current SmartSpectra Edge Sentinel challenge prototype. It is not a medical device and is not intended for diagnosis, treatment, or medical decision-making.

## In-app consent dialog text
When launching the measurement flow, the app presents the following explicit consent dialog:

> **Uso de la cámara y señales:**
> Si continúas, SmartSpectra usará la cámara frontal para procesar señales de pulso y respiración. Esta versión experimental exige una ventana temporal candidata de 20 segundos con pares nuevos de pulso/respiración, antes de codificar una trama LBH fija de 16 bytes en memoria. Solo acepta en el evaluador muestras con stable=true, confidence finita y positiva, timestamps crecientes, diferencia de par de hasta 100 ms y huecos entre pares no mayores que 3 segundos. Los 20 segundos, 100 ms y 3 segundos son parámetros provisionales de ensayo, no umbrales médicos, garantías clínicas ni requisitos de los SDK. Los campos y la trama no se guardan, escriben en logs ni se transmiten mediante esta app; el array de bytes se borra tras codificar. El procesamiento y la telemetría de Presage son independientes; consulta su documentación y política de privacidad. Esta app no desactiva la telemetría del SDK. Puedes cancelar antes de iniciar o detener la medición después. No es un dispositivo médico.

## Signals and in-memory LBH processing
The current callback reads available pulse metrics from cardio.pulseRateList. The app integrates an experimental session-consensus layer (`SmartSpectraConsensusEvaluator`) enforcing a 20-second stability window and an in-memory bridge/encoder (`PresageLbhBridge`, `LbhEncoder`) that builds a validated 16-byte fixed LBH frame in memory when criteria are met. 

The app sets `imageOutputEnabled = false` and its current source code does not deliberately record/export camera video, write biometric measurements to disk, or transmit LBH frames over a network. The generated byte array is held strictly in volatile memory and discarded after encoding. This describes app-controlled behavior in this repository; it is not a claim about SDK network communication or provider-side retention.

## SmartSpectra telemetry and provider handling
Presage documents SmartSpectra session telemetry as enabled by default. Its documentation describes an aggregate diagnostic summary per measurement session, including SDK/package, platform/runtime/device characteristics, session source/outcome, performance/validation counts, coarse error code for a failed session, and a session timestamp. Presage states that this telemetry excludes raw video or image frames, measured vital values, free-text errors, user identifiers, and stable device identifiers. This app does not explicitly disable telemetry. These are provider statements, not an independent network audit. Consult the Presage telemetry and privacy documentation and Presage privacy policy.

## Development credential and APK
The development setup reads the Presage API key from a local properties file outside the repository and exposes it through `BuildConfig`. Do not publish or distribute an APK/AAB containing an active development key. Rotate or revoke an exposed key.
